# Demo Script

1. Open the dashboard and log in as `admin`.
2. Create and start a campaign.
3. Show the generated eligible patient tasks.
4. Schedule the queue and point out the capacity limit.
5. Simulate NO_ANSWER and show RETRY_SCHEDULED.
6. Simulate DROPPED and show preserved partial context/manual/retry behavior.
7. Simulate CALLBACK and show CALLBACK_SCHEDULED.
8. Simulate URGENT and show structured triage + escalation.
9. Open escalation, inspect evidence, and resolve as human reviewer.
10. Run safety evaluation and show TP/FP/TN/FN/FNR.
11. Open `/docs` to show API surface.
12. Explain that the prototype intentionally uses simulated telephony and mock EHR.
